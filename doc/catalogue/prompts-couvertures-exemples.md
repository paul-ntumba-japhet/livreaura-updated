# Prompts des 12 couvertures d’exemple

Ces images sont des couvertures fictives pour la page Catalogue. Le site les charge depuis `frontend/public/catalogue-exemples/`. Une fois le fichier déposé, l’adresse publique est `/catalogue-exemples/` suivi du nom.

Format commun pour les douze images :

- PNG, portrait, ratio 3:4, par exemple 1200 × 1600 px
- couverture de livre illustrée, sans photo d’une personne réelle
- le titre est écrit exactement comme indiqué, en français, lisible
- aucun logo Livreaura, aucun prix, aucun code-barres, aucun filigrane
